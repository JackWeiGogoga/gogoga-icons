# Changelog

All notable changes to gogoga icons are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/). 中文版见 [CHANGELOG.zh-CN.md](CHANGELOG.zh-CN.md).

## [0.1.4] - 2026-10-18

### Added
- Funding link.

## [0.1.3] - 2026-10-18

### Changed
- Re-released for the community plugin review. No visible changes.

## [0.1.2] - 2026-10-15

### Added
- English README with a Simplified Chinese translation.

### Fixed
- Icons drawn before the plugin loaded (ribbon, tab headers, file tree and so on) are now replaced with Phosphor icons too.

## [0.1.1] - 2026-10-14

### Changed
- Reworded the plugin description.

## [0.1.0] - 2026-10-14

First public release.

### Added
- Replaces about 110 of Obsidian's Lucide interface icons with Phosphor icons (regular weight), as used by Tolaria.
